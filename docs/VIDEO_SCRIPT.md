# Demo video script (target 1:50, hard limit 2:00)

About 240 words of narration at a calm pace (~2.2 words per second). Record the screen at 1080p.
**No music** (or only royalty-free music you have the rights to). Show only PULSE and its README.

## Before recording
- Open https://pulse-k9mh.onrender.com **2–3 minutes before** so the free server is awake.
- Browser full screen, zoom 100%, close other tabs. Language English, Audience Casual, speed 30×.
- Recorder: Xbox Game Bar (Win+Alt+R) or OBS Studio (both free).
- Do one practice run; cut pauses in editing (Clipchamp, built into Windows, is free).

## Scenes

| Time | Show on screen | Say |
|---|---|---|
| 0:00–0:12 | Dashboard at kick-off; point at the "Synthetic data" badge | "Football stories don't end with the scoreline. PULSE watches a match as it happens and explains what changed, and proves every number it uses. All data here is synthetic, from our own match simulator." |
| 0:12–0:30 | Press **Play** at 30×; key events appear with coloured labels; momentum bars grow | "The match streams live over WebSocket. Instead of every pass, PULSE labels the moments that matter: chances created, pressing, balls won high. The chart shows who's on top, minute by minute." |
| 0:30–0:55 | Drag to **62'**, press Play; the **Alert 63'** card appears; click **Show evidence** | "At 63 minutes the detector spots a real shift: Eastvale's high press jumped from 5 to 11 presses. A Storyteller agent built on Microsoft Agent Framework writes the insight. Before you ever see it, a fact-checker verifies every number and every cited event against the data. Here's the evidence." |
| 0:55–1:12 | Let it play past 64'; the **On the pitch** card shows the goal build-up (steps 1–6); point at **Turning points** | "One minute later, Eastvale equalise. On the pitch you can see how: the press, a Northbridge pass lost in their own third, the ball won back, one pass, and a goal eight seconds later. PULSE shows the timing link with the press, but never claims it as the cause." |
| 1:12–1:25 | Switch Audience to **Analyst** (numbers panel, chart scale), then Language to **Bahasa Indonesia** | "Fans get plain language with at most two numbers. Analysts get rates, time windows and a numbers panel. And everything works in English and Bahasa Indonesia." |
| 1:25–1:45 | README on GitHub: architecture diagram, then the "Built to be trusted" table | "The design rule: AI words the story, but never decides the facts. If the agent fails the check twice or is offline, a verified template takes over, so the page never breaks. We measured the detector on unseen matches and publish its error rate." |
| 1:45–1:55 | Back to the dashboard; show the URL | "PULSE: trustworthy, multilingual match intelligence that broadcasters and clubs can run unattended. Try it at the link below." |
